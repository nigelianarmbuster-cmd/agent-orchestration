What you're building

This page walks a first-time user through the OpenCode agent-orchestration setup described in the guides: an OpenCode instance where a supervisor agent plans the work and delegates to about 44 tiered agents across three prepaid providers, each used where it is genuinely strongest. DeepSeek is the primary workhorse — the supervisor, junior agents, and role-mules all run on V4.1 Flash. Claude (Sonnet 5 on the mid tier, Opus 4.8 on the senior tier) acts as the quality gates that review, secure, and fact-check the work. Gemini 3.8 Flash handles research, planning, and the multimodal screenshot observer. Optional free local models run via Ollama. The observer plugin reads screenshots you paste into the chat — it needs a Gemini key. Every provider you actually use must be funded first: add billing or prepaid credits before you start. Funding is never optional, and free tiers are not a substitute for it.

This page walks a first-time user through the OpenCode agent-orchestration setup described in the guides: an OpenCode instance where a supervisor agent plans the work and delegates to about 44 tiered agents. On the budget plan, DeepSeek is the whole core workflow — the supervisor and all the junior agents run on V4.1 Flash. The Claude mid-tier and senior agents (Claude Sonnet 5 / Opus 4.8) stay configured but inactive until you add an Anthropic key later. Fund DeepSeek before you start. The only free-tier allowance on this page is the Gemini key, and in Budget it is for the Observer (pasted screenshots) only — not for the Gemini researcher/planner agents. Local models via Ollama are free.

Why three providers instead of one? Each is used for what it does best, and spend is deliberately spread across all three prepaid balances. DeepSeek is the affordable workhorse, so it carries the bulk of the volume; Claude keeps the quality gates (mid-tier review/security/fact-checking on Sonnet 5) and all senior judgment (Opus 4.8), where its subtle bug-detection, adversarial review, and exact-quote fidelity genuinely win; Gemini 3.8 Flash is intro-priced and cost-effective, so it handles long-context research, planning, and vision. Effort is tiered too — juniors run low effort, mid/senior run high, and the role-mules run with thinking switched off. Researcher and planner are the only mid roles routed to Gemini (not Claude) because Gemini 3.8 Flash is genuinely competitive there at low quality risk, and the balance is set structurally in the agent files — a deterministic ~64/26/10 DeepSeek/Anthropic/Google split — rather than by prompt-guessing how to route each task.

Install the OpenCode app & add your keys

Steps 8–14

One download, then plain clicking

You download OpenCode once and open it like any other app (step 8). Everything after that happens in OpenCode's own windows — adding keys is a paste in Settings, and the rest is typing in the chat box.

8

Download the OpenCode app

Required 8/20

This setup is built for OpenCode 1.19.5, so download exactly this file. It installs like any other app.

Download for Apple Silicon Download for Intel Download for Windows (64-bit)

First check which kind of Mac you have: click the Apple menu → About This Mac → look at Chip. If it says Apple M… (for example "Apple M2"), download the Apple Silicon file. If it says Intel, download the Intel file.

  1. Your Mac downloads a .dmg file — open it when it finishes.
  2. A window opens with the OpenCode icon and an Applications folder. Drag OpenCode onto the Applications folder, then close the window.
  3. Open Applications and double-click OpenCode. macOS may say it cannot check the app for malicious software, or that it is from an unidentified developer. If so, click Done, then right-click (or Control-click) the OpenCode icon → Open → Open again in the dialog that appears. If the button is not offered, open System Settings → Privacy & Security and click Open Anyway next to the OpenCode message.
  4. Open your Downloads folder and double-click opencode-desktop-win-x64.exe.
  5. If Windows shows a blue "Windows protected your PC" screen, click More info, then Run anyway. Windows shows this for any program it has not seen before.
  6. Let the installer run and finish. It installs for your user account and adds an OpenCode entry to the Start menu.

Why this download and not the download page? The download page at opencode.ai/download currently serves OpenCode 2 (2.2.5), which these config files are not built for. These links are the pinned OpenCode 1.19.5 app.

Later, the app may offer an OpenCode 2 update

The app updates itself automatically. Decline any update that says it moves OpenCode to version 2 — these config files are only built for 1.19.5.

Release page for reference: OpenCode 1.19.5.

15

Ask OpenCode to install the config

Required 15/20

Paste one message into OpenCode's message box and let the agent do the work. It downloads the configuration, puts it in the right folder, and sets everything up.

You, in OpenCode

Install your own configuration. Clone https://github.com/nigelianarmbuster-cmd/opencode-config.git into your global OpenCode config folder — ~/.config/opencode on macOS, %USERPROFILE%\.config\opencode on Windows — and set up its dependencies. If that folder already exists, keep the files that are already there and add the missing ones. Tell me when it is done.

On your Mac the folder it writes to is ~/.config/opencode (that is /Users/<your-name>/.config/opencode). A few things to know while it runs:

On Windows the folder it writes to is %USERPROFILE%\.config\opencode — that is C:\Users\<you>\.config\opencode. A few things to know while it runs:

  • OpenCode runs the commands on your computer itself, and does not ask before each one.
  • Any permission requests appear as dialogs in the app. If a dialog asks for permission to work outside your project folder, review it carefully before you approve.
  • It may need git — which comes with the Xcode command-line toolsif the app asks to install something, read the dialog first. Allow it only if the dialog names git.
  • Windows Defender Firewall or SmartScreen may pop up; Windows does this for any program it has not seen before.
  • Stop the run from the app — use the stop button in the app while it is working — if anything looks wrong.
  • If the folder already exists and is not empty, the agent adds the missing files instead of failing. If it fails or says "destination path already exists" and stops, ask the app to try again — or ask the person who shared this guide.

Learn how to customize your OpenCode config

Optional — nothing to do now

Open the customization guide

Your setup ships with extra add-on tools called MCP servers. All of them are dormant — declared in the config but switched off — so they cost nothing and do nothing until you turn one on.

1. The dormant tools in your setup

ToolWhat it does
playwrightBrowser automation: screenshots, page inspection, click-through testing. First enable downloads browser binaries (a few hundred MB).
chrome-devtoolsConnects to a real Chrome browser for debugging, console and performance checks.
elevenlabsText-to-speech voice generation. Needs an ElevenLabs account and key.
yt-dlpDownloads videos and audio from YouTube and other sites.
vercelManages Vercel deployments. Needs a Vercel token.
gemini-api-docsGives the agents current Gemini API documentation.
context7Gives the agents current documentation for libraries and frameworks.
githubWorks with GitHub repositories. Needs Docker and a personal access token — full steps in the macOS/Windows guides.
macos-useControls your Mac's desktop (macOS only; needs a helper binary).
railwayDeploys apps to Railway via the CLI (railway login, railway up). Keep this one off — enabling it has broken the Gemini Observer.

2. Why they are off, and how to turn one on

Every enabled MCP server loads at startup and adds tokens to each conversation, and some pull down packages or need their own accounts and keys. The core setup needs none of them, so they ship dormant — switch on exactly what you use.

To enable one: open opencode.json in your config folder (~/.config/opencode on macOS, %USERPROFILE%\.config\opencode on Windows), find the tool's name under "mcp", change "enabled": false to "enabled": true, save, and restart OpenCode. Check it is live with opencode mcp list. Some tools need extra setup (a key, token, or CLI) — noted in the table above.

Costs & safety

  • Everything is prepaid — you add money, and usage is deducted from your balance.
  • API keys are stored by OpenCode itself in its own credential store — not in this repo, and not in a file you edit. Never paste a key into a chat, an issue, or a commit.
  • The agent can run commands on your computer when you paste an instruction — step 15 is the main one here. The commands do not prompt individually. You may be asked once to allow work in your home config folder (that is the only folder it needs here); if any other folder is named, choose no. You can stop the run from the app.
  • Amounts change — verify in each console when you purchase. Anthropic credits expire after one year and are non-refundable.
  • Free tiers — Full plan: you pay for DeepSeek, Anthropic, and Gemini. Budget plan: you pay for DeepSeek; in Budget the only free-tier allowance is Gemini for the Observer (pasted screenshots) — the Gemini agents must not be run on it. Funding is never optional.

Troubleshooting

  • Screenshots return nothing, or the Observer stays silent. The Gemini key is not reaching OpenCode — in Settings → Providers, check that Google has a key saved, and reconnect it if not (step 12). Then: an old environment variable overrides the saved key, so ask OpenCode in the chat box: Check whether any GOOGLE or GEMINI environment variable is set, and remove it if so, then tell me. Restart the app afterwards. (If you can use a terminal: printenv | grep -i -E 'GOOGLE|GEMINI' on macOS, Get-ChildItem Env: | Where-Object Name -match 'GOOGLE|GEMINI' in PowerShell.)
  • The app will not open, or the installer was blocked. macOS said it was from an "unidentified developer": click Done, then right-click (or Control-click) the OpenCode icon in Applications → Open → Open. If the button is not offered, go to System Settings → Privacy & Security and click Open Anyway next to the OpenCode message. If Windows showed "Windows protected your PC", open the downloaded opencode-desktop-win-x64.exe again, click More info, then Run anyway. If it still will not install, restart the computer and run the installer again.
  • A provider key does not stick in Settings → Providers. Re-copy the key from your password manager — a missing character or a trailing space is the usual cause — and save it again. Make sure the key belongs to the provider you selected: an Anthropic key in the Google entry will not work, and a key that was deleted or revoked in the provider's console will not work either.
  • A model is missing from the picker. The key for that provider is missing or wrong. Re-add it in Settings → Providers (step 10 for DeepSeek, step 11 for Anthropic, step 12 for Google, step 13 for xAI) and save it again — the models appear in the picker as soon as the key is saved.
  • The app offers an OpenCode 2 update. Decline it. These config files are built for OpenCode 1.19.5 only, and OpenCode 2 is not compatible. Keep using the installed app and dismiss the update prompt.
  • "model not found", or an agent errors on every reply. That is almost always a key or funding problem. Open Settings → Providers and check the provider's key is there, then pick the model again in the model picker. Check the provider console shows a funded balance — an empty balance fails exactly like a missing key.
  • No supervisor, or the agent team is missing. The config did not load. Redo step 15 (ask OpenCode to install the config), answer any questions it asks (step 16), and restart the app (step 17). The agent picker should then list supervisor.
  • A permission dialog names a folder you do not recognise. Choose no. The only folder this setup needs is ~/.config/opencode (macOS) or %USERPROFILE%\.config\opencode (Windows).
  • Gemini agents fail or behave oddly in the Budget plan. In Budget, the free tier is for pasted screenshots only. Add billing to the Google key before using the Gemini researcher or planner.
  • The progress bar looks wrong. Progress is stored only in this browser. Use Reset in the top bar to start the checklist again.
