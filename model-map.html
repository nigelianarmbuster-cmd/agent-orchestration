Notes on effort & thinking

Effort and thinking are controlled differently per provider:

  • DeepSeek — a thinking toggle (on/off) plus reasoningEffort (low/medium/high/max). Supervisor uses reasoningEffort: high; juniors/mules use low + thinking off.
  • Anthropic (Claude) — no simple on/off. Modern models (Sonnet 5, Opus 4.8) use adaptive thinking: Anthropic dynamically budgets thinking tokens against an effort level (low/medium/high/xhigh/max). Mid tier runs variant: medium (adaptive medium); senior runs variant: high. claude-mule disables thinking entirely (thinking: { type: disabled }) at effort: low.
  • Gemini — uses thinkingLevel (minimal/low/medium/high), not a token budget. Researcher/planner run variant: high (thinking level high); gemini-mule sets thinkingLevel: minimal.

Global default (DeepSeek V4.1 Flash): when running V4.1 Flash as the supervisor, it lands on reasoningEffort: max with thinking on — overridable manually. Juniors and mules pin themselves to low + thinking off at the agent level, which overrides the global.

No Claude Haiku tier: the high-volume cheap work runs on DeepSeek V4.1 Flash (juniors + mules), which is cheaper than Haiku. Claude is reserved for the quality gates (Sonnet 5 mid, Opus 4.8 senior) — there is no "cheap Claude" tier in this wiring.

Cost rationale: DeepSeek V4.1 Flash is the high-volume workhorse, so juniors/mules run cheap (low effort, no thinking). Claude carries the quality gates (review, security, quote-auditor, debugger) at adaptive effort medium. Gemini 3.7 Flash handles research, planning, and vision. Senior Claude Opus 4.8 is the highest-stakes tier (adaptive high), used sparingly.
