What you're building

This page walks a first-time user through the OpenCode agent-orchestration setup described in the guides: an OpenCode instance where a supervisor agent plans the work and delegates to about 43 tiered agents — DeepSeek V4 Pro (supervisor and juniors), Claude Sonnet 5 (mid tier), Claude Opus 4.8 (senior tier), Gemini (research and multimodal), and optional free local models via Ollama. The observer plugin reads screenshots you paste into the chat — it needs a Gemini key.

  • Default agent: supervisor
  • Default model: deepseek/deepseek-v4-pro
  • Everything is prepaid — no subscription needed
  • Plan on 30–45 minutes, start to finish
  • Budget plan: fund DeepSeek only — the whole core workflow still runs on it
  • Past screenshots are read by the observer plugin (needs a Gemini key)

2

Install OpenCode

Required 2/18

Install OpenCode globally with npm, then verify the version. If the command isn't found, close your terminal and open a new window (on Windows, restart if that still fails).

$PS> npm install -g opencode-ai
$PS> opencode --version

Also works via Homebrew: brew install anomalyco/tap/opencode — you still need Node.js for section 2.

Also works via Scoop or Chocolatey: scoop install opencode / choco install opencode — you still need Node.js for section 2.

Get the configuration files

Steps 3–5

3

Download the configuration files

Required 3/18

The setup is a public GitHub repo — no GitHub account needed. Easiest: open it, click Code → Download ZIP, then unzip (you get a folder called opencode-config-main). With git installed, the command below does it in one step.

Open the config repo 
$ git clone https://github.com/nigelianarmbuster-cmd/opencode-config.git ~/.config/opencode
PS> git clone https://github.com/nigelianarmbuster-cmd/opencode-config.git "$env:USERPROFILE\.config\opencode"

If git isn't installed, just use the ZIP — you don't need it.

4

Put the config files in place

Required 4/18

Create the config folder, then move the repo's contents into it — the seven items themselves, not the outer folder. Skip this step if you used git clone — the folder already exists.

$ mkdir -p ~/.config/opencode
PS> New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.config\opencode"
In Finder press Command+Shift+G, type ~/.config/opencode, press Return — then drag the seven items from the unzipped folder into it.
Press Win+R, paste %USERPROFILE%\.config\opencode, press Enter — then drag the seven items from the unzipped folder into it.

Copy these seven items in: opencode.json, opencode.jsonc, AGENTS.md, agents/ (the folder of ~43 agent files), observer-bridge.js, package.json, package-lock.json.

5

Install the config's plugin

Required 5/18

Inside the config folder, run npm install. This installs @opencode-ai/plugin and creates a local node_modules folder — expected, and you won't touch it again.

$ cd ~/.config/opencode
$ npm install
PS> cd "$env:USERPROFILE\.config\opencode"
PS> npm install

14

Create the .env file for Gemini

Required Recommended (free) 14/18

OpenCode has no login flow for Gemini — it reads the key from a .env file in the folder where you run OpenCode. Make a project folder, add a file named exactly .env, and put this line inside it:

GEMINI_API_KEY=PASTE_YOUR_KEY_HERE

Replace PASTE_YOUR_KEY_HERE with your real key — no spaces, no quotes around the key itself. Want Grok too? Add a second line: XAI_API_KEY=PASTE_YOUR_KEY_HERE. OpenCode also accepts GOOGLE_API_KEY or GOOGLE_GENERATIVE_AI_API_KEY instead of GEMINI_API_KEY.

Budget: still do this — the Gemini key is free (free tier) and keeps the screenshot feature working.

$ mkdir ~/ai-test
$ cd ~/ai-test
$ echo 'GEMINI_API_KEY=PASTE_YOUR_KEY_HERE' > .env
PS> mkdir $HOME\ai-test
PS> cd $HOME\ai-test
PS> notepad .env

Notepad asks whether to create the new file — click Yes, type the line above, press Ctrl+S, close. Prefer typing? Set-Content -Path .env -Value 'GEMINI_API_KEY=PASTE_YOUR_KEY_HERE' does the same thing.

Costs & safety

  • Everything is prepaid — you add money, and usage is deducted from your balance.
  • API keys are secrets. Never paste them into a chat, and never commit them to git.
  • The .env file contains secrets too — keep it out of chats and out of git.
  • Amounts change — verify in each console when you purchase. Anthropic credits expire after one year and are non-refundable.
